# Symply Budget icon system guide

## Visual language

- 24×24 grid
- 1.8-point rounded monoline stroke
- no decorative circles behind navigation icons
- selected icons use the exact green money gradient
- inactive icons are monochrome
- minimum touch target: 44×44

## Selected gradient

`#5FD49A → #2BB673 → #239A61 → #1B7A4C`

## Inactive colors

- Dark UI: `#92A6A0`
- Light UI: `#536A63`

## Status language

Complete, In progress, Pending, Overdue, and Skipped all use a consistent circular structure. Semantic-color exports are included separately.

## Brand mark

The primary mark is a painted green ring wrapped around a slightly stylized dollar sign. Preserve the open brush edge and subtle bristles.
