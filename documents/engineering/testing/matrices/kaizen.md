**Architecture note (drives every row):** Kaizen is **local-first**. All domain writes land in on-device SQLite (`expo-sqlite`, 23 `kaizen_*` tables) and are pushed later by `POST /api/v1/sync`. Therefore:

- `Console verify` for a local write is `n/a (local)` — but the row's **Expected** must still name the concrete table/column that changes. A MUTATION row that only asserts a label change is **not** contract-compliant.
- Only AI (`/api/v1/ai/*`), coach chat (`/api/v1/kaizen/coach-chat/*`), sync (`/api/v1/sync`) and auth rows have a real network assertion.
