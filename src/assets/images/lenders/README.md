# Bundled lender logos

Size-normalized lender wordmark PNGs live here, one per lender **slug**
(e.g. `td.png`, `rbc.png`, `national-bank.png`). They are generated — do not
hand-edit or hand-add files.

- **Generated by:** `scripts/normalize-lender-logos.mjs` (`npm run logos:lenders`)
  from sources in `scripts/lender-logo-sources/` and/or `scripts/lender-logos.manifest.mjs`.
- **Consumed by:** `src/utils/lender-logos.generated.ts` (require-map) → `<LenderLogo>`.
- **Format:** trimmed, letterboxed onto a transparent 160×160 square.

Until logos are added, this folder is empty and every lender renders a branded
monogram tile. See `scripts/lender-logo-sources/README.md` for the trademark note.
